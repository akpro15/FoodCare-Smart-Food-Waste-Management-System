# 🍱 FoodCare – Smart Food Waste Management System

FoodCare is a full-stack MERN web application that helps reduce food waste by connecting Donors, NGOs, Riders, and Admins through one smart platform.

---

## 🚀 Live Demo

Frontend:
[(https://food-care-smart-food-waste-manageme.vercel.app/)

Backend:
[(https://foodcare-backend.onrender.com)

---

## ✨ Features

- 🔐 Role-Based Authentication
- 🍛 Food Donation System
- 🏢 NGO Dashboard
- 🚴 Rider Dashboard
- 👨‍💼 Admin Dashboard
- 📦 Live Order Tracking
- 📜 Donation History
- 📱 Responsive Modern UI
- ☁️ Cloud Deployment

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### Deployment
- Vercel
- Render

---

## 👨‍💻 User Roles

### Donor
- Donate food
- Track donation status
- View delivery history

### NGO
- Accept food donations
- Manage deliveries
- Track completed orders

### Rider
- Deliver food
- Update delivery status
- View delivery history

### Admin
- Monitor all donations
- Track deliveries
- View analytics dashboard

## 📂 Installation

```bash
git clone https://github.com/akpro15/FoodCare-Smart-Food-Waste-Management-System
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
node server.js
```

- Backend deployed on Render
